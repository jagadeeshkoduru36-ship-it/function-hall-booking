# Function Hall Booking

A full-stack web application for online function hall booking.

## Technology Stack
- Frontend: React.js
- Main Backend: Java Spring Boot
- Database: PostgreSQL
- Database Access: JDBC
- Secondary Service: Node.js
- Deployment: Render
- Source Control: GitHub

## Main Features
- User registration and login
- View available function halls
- Hall capacity, location and pricing
- Chair selection and quantity
- Decoration selection
- Food selection (Veg / Non-Veg / Both, guests and price per person)
- Parking selection
- Room selection and quantity
- Automatic total-cost calculation
- Booking management

## Project Structure
- `frontend/` React application
- `java-backend/` Spring Boot + JDBC API
- `node-service/` Node.js supporting service
- `database/` PostgreSQL schema
- `render.yaml` Render deployment blueprint
